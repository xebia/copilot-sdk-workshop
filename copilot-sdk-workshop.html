Choose the boundary first

Already an agent.
Deliberately scoped.

TOOL AVAILABILITY

The default runtime exposes built-in tools. Lab 1 allows none. Later labs allow only their own read-only capabilities.

Registering a custom tool does not remove built-ins. Use an explicit AvailableTools allowlist.

PERMISSION POLICY

ApproveAll is a classroom shortcut for this narrow tool set. It is not a sandbox or production policy.

It throws when managed settings are enabled. Follow organisation policy; never bypass it to make a demo work.

The agent loop exists from the first session. We progressively add domain capabilities, not the runtime itself.

History, tool-call results and planning context persist. Process memory and tool implementations do not. Re-register tools and permission handlers when needed. This demo has no domain tools.

Disposing a session frees runtime resources but keeps saved history. Deletion is a separate operation.

Working with agent files

Instructions
are not tools.

Frontmatter describes when to delegate and which registered tools the specialist may use.

The Markdown body defines its role, evidence requirements and report format.

FILE SHAPE · REPLACE THE PLACEHOLDERS
